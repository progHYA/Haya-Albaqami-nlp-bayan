# Final submission checklist

Before pushing this package to GitHub:

1. Put the executed student notebooks in `/notebooks/` (not untouched course copies).
2. Rerun notebooks 03–08 with project artefacts where the evaluation requires them.
3. Save small JSON/CSV reports under `/reports/`.
4. Run the repository validator and preflight.
5. Add the validator reports under `/reports/`.
6. Fill `PROJECT_SUMMARY.json` and `SUBMISSION.yml` with the evaluated commit/tag.
7. Link each report to a concrete notebook/output/commit.
8. Do not call `SYSTEMS_SMOKE`, `COURSE_FIXTURE`, or smoke metrics final project performance.
